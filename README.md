# Analog Clock with Digital Display

A simple real-time analog clock with a digital time display, created as part of my learning journey using HTML, CSS, and JavaScript.

### Features
- Displays current time using analog clock hands.
- Shows digital time below the clock.
- Updates automatically every second.
- Displays time in 12-hour format with AM/PM.

### Technologies Used
- HTML5
- CSS3
- JavaScript

### Live Demo
[View Live Demo](https://meghanayannam21.github.io/analog-clock/)

### Run Locally
1. Clone this repository.
2. Open `index.html` in your browser.

### Learning Outcomes
Practiced JavaScript Date objects, setInterval(), DOM manipulation, and CSS transformations.
